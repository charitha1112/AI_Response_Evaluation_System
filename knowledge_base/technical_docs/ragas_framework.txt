RAGAS FRAMEWORK FOR RAG EVALUATION

1. What is RAGAS?

RAGAS stands for Retrieval-Augmented Generation Assessment.

It is an evaluation framework designed to assess the performance and quality of Retrieval-Augmented Generation (RAG) systems.

It provides metrics to evaluate retrieved context and generated answers.

2. Why is RAGAS Used?

- Evaluates RAG system performance.
- Measures the relevance of retrieved information.
- Checks whether generated answers are supported by context.
- Helps identify retrieval and generation problems.
- Reduces the need for entirely manual evaluation.
- Supports systematic improvement of RAG applications.

3. Important RAGAS Metrics

A. Faithfulness:

Measures whether the generated answer is supported by the retrieved context.

A faithful response should not introduce unsupported information.

B. Answer Relevancy:

Measures how relevant the generated answer is to the user's question.

C. Context Precision:

Measures whether relevant retrieved information is ranked above irrelevant information.

D. Context Recall:

Measures whether the retrieved context contains the information needed to answer the question.

E. Context Relevancy:

Measures how relevant the retrieved context is to the user's question.

F. Factual Correctness:

Measures whether the generated response agrees with a reference answer.

G. Noise Sensitivity:

Measures how much irrelevant information in the retrieved context affects the generated answer.

4. How RAGAS Works

Step 1: Prepare an evaluation dataset.

Step 2: Provide questions, generated answers, retrieved contexts, and reference answers where required.

Step 3: Select appropriate evaluation metrics.

Step 4: Run the evaluation process.

Step 5: Calculate metric scores.

Step 6: Analyze the results to identify weaknesses in the RAG system.

5. Typical RAGAS Evaluation Data

A RAG evaluation dataset may contain:

- Question: The user's input question.
- Answer: The response generated by the AI system.
- Contexts: Documents retrieved by the RAG system.
- Ground Truth: The expected reference answer, when available.

6. Example of RAGAS Evaluation

Question:
What is Machine Learning?

Retrieved Context:
Machine Learning is a subset of Artificial Intelligence that enables computers to learn patterns from data.

Generated Answer:
Machine Learning allows computers to learn from data.

Reference Answer:
Machine Learning enables computers to learn patterns from data without being explicitly programmed for every task.

Possible evaluation:

Faithfulness:
The generated answer is supported by the retrieved context.

Answer Relevancy:
The answer directly addresses the question.

Context Precision:
The retrieved information is relevant.

Context Recall:
The context contains useful information needed to answer the question.

Factual Correctness:
The answer is consistent with the reference answer.

7. Advantages of RAGAS

- Provides multiple RAG evaluation metrics.
- Supports systematic evaluation.
- Helps identify retrieval and generation weaknesses.
- Can reduce manual evaluation effort.
- Supports evaluation using reference information and model-based judgments.

8. Limitations of RAGAS

- Some metrics depend on language models as evaluators.
- Evaluation results may vary depending on the judge model.
- Poor reference data can affect evaluation quality.
- Scores should be interpreted with the evaluation context.
- It does not guarantee that every factual error will be detected.

9. RAGAS in This Project

RAGAS provides useful evaluation concepts for the AI Evaluation System.

The project can use its evaluation dimensions to assess:

- Whether the retrieved context is relevant.
- Whether the answer is supported by evidence.
- Whether the response addresses the question.
- Whether the response agrees with reference information.

These concepts can help design the Relevance Judge, Accuracy Judge, and Hallucination Detection Agent.

10. Conclusion

RAGAS is a useful framework for evaluating Retrieval-Augmented Generation systems. Its metrics help measure retrieval quality, answer relevance, faithfulness, and factual correctness.
